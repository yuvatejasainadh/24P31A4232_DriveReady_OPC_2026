Why Token Usage Matters:
1. Cost: LLM APIs bill per input token (system prompt + knowledge base + chat history + user query) and per output token generated.
2. Context Limits: Every model has a finite context window. Passing huge unpruned histories or massive knowledge bases increases latency, cost, and risk of hitting token limits.
